# MaxOnDroid

Приложение для Windows, которое управляет Android-устройствами в домашней сети через `adb`: телевизорами на Android TV и телефонами. Подключение по USB и Wi-Fi, сведения об устройстве, перезагрузка, а дальше установка и удаление приложений, чистка от рекламы, пульт, экран, файлы и консоль. Все действия записываются в журнал в виде обычных команд `adb`, поэтому видно, что делает каждая кнопка.

*English summary below.*

> **Состояние:** этап 3 из 5. Готовы окно, список устройств, подключение (USB, адрес, сопряжение по коду и QR, поиск в сети), вкладки «Обзор», «Приложения», «Чистка», «Пульт» и «Экран», журнал команд, русский и английский языки, светлая и тёмная темы. Установщика пока нет: приложение запускается из исходников (инструкция ниже).

## Что умеет сейчас

- **Список устройств с номерками.** Каждое устройство получает свой номер (01, 02, …), который сохраняется за ним. Если телефон подключён одновременно по USB и Wi-Fi, это одно устройство. Форма номерка показывает состояние: сплошной — подключено, контур — не в сети, со срезом — ждёт разрешения на устройстве, жёлтое кольцо — открыт небезопасный сетевой adb.
- **Подключение:**
  - по USB (с подсказками по драйверам);
  - сопряжение по шестизначному коду (Android 11+, в том числе телевизоры);
  - сопряжение по QR-коду (телефоны на Android 11+);
  - по адресу `IP:порт` (уже сопряжённые устройства или старый режим `adb tcpip`);
  - поиск устройств в сети (mDNS), без сканирования подсети.
- **Автоматическое переподключение** сохранённых Wi-Fi-устройств. Оно идёт в фоне: список устройств появляется сразу, даже если сохранённые устройства не в сети. Подключение и отключение видно мгновенно (`adb track-devices`), без ожидания очередного опроса. Старые адреса телефона, у которого сменился порт отладки по Wi-Fi, не превращаются во второе устройство в списке: MaxOnDroid отключает их сам.
- **Обзор:** модель, версия Android и патч безопасности, батарея, память, экран, IP-адрес, способ подключения. Перезагрузка в систему, recovery или загрузчик (с подтверждением).
- **Безопасность сети:** если на устройстве открыт старый сетевой adb (подключиться может кто угодно в сети), приложение предупреждает и даёт выключить его одной кнопкой.
- **Журнал команд** с номерком устройства у каждой строки. Пишется и в файл. Коды сопряжения в журнал не попадают.
- **Приложения:** все пакеты устройства с поиском и фильтрами по издателю, типу и состоянию. Установка APK и наборов `.apks`, `.xapk`, `.apkm` кнопкой или перетаскиванием в окно (из набора выбираются части под процессор и экран устройства). Запуск, остановка, отключение и включение, удаление и возврат, очистка данных, сохранение APK на компьютер (приложение из нескольких частей сохраняется одним файлом `.apks`).
- **Чистка:** пакеты устройства, сгруппированные по издателю: Android, производитель устройства, Google, Яндекс и другие; издатели с одним приложением собраны в «Остальные». У каждого пакета риск удаления от 1 («без последствий для системы», само приложение пропадёт) до 4 («устройство может не загрузиться») и описание из базы [UAD-ng](https://github.com/Universal-Debloater-Alliance/universal-android-debloater-next-generation). Отмеченные пакеты удаляются для пользователя или отключаются. Пресеты в JSON, чтобы применить тот же набор к другому устройству или отдать другу. «История изменений» отменяет любое изменение или все сразу.
- **Пульт:** крестовина и «ОК», «Назад», «Домой», «Меню», громкость, питание, каналы, перемотка и пауза. Удержание кнопки — долгое нажатие. Пока пульт в фокусе, работает клавиатура компьютера (стрелки, Enter, Esc, пробел, +/−, PgUp/PgDn). Поле для отправки текста в поле ввода на устройстве (латиница, цифры, символы).
- **Экран:** изображение устройства в отдельном окне через [scrcpy](https://github.com/Genymobile/scrcpy) с пресетами «Качество» и «Скорость» и дополнительными параметрами (размер, битрейт до 50 Мбит/с с подсказкой, частота кадров, звук, выключить экран устройства, поверх всех окон, только просмотр, клавиатура как физическая для ввода по-русски). Параметры запоминаются для каждого устройства; телевизор начинает с пресета «Скорость», потому что свой 4K-экран он обычно не успевает кодировать. Если поменять параметр при открытом окне, оно само откроется заново с новыми настройками. Запись идёт в MP4 (звук AAC, открывается встроенным плеером Windows) или, по выбору, в MKV; при остановке scrcpy закрывается штатно и успевает дописать файл. Пока окно открыто, видно реальное число кадров в секунду. Скриншоты в `Изображения\MaxOnDroid` с предпросмотром и копированием в буфер. Можно открыть экраны нескольких устройств одновременно. Защищённое видео (онлайн-кинотеатры) показывается чёрным: так работает защита от копирования.
- **Файлы:** папки устройства начиная с `/sdcard`, переход по адресу, сортировка (папки всегда сверху). Загрузка файлов и папок на устройство кнопкой или перетаскиванием из Проводника на вкладку (APK здесь копируются, а не устанавливаются), скачивание на компьютер в выбранную папку, новая папка, переименование, удаление с подтверждением. Копирование можно отменить. Корневые папки памяти и системы удалить отсюда нельзя. Вкладка вмещается в окно на полэкрана.
- **Консоль:** два режима. В режиме adb пишется то, что после `adb` в командной строке; `-s` для выбранного устройства подставляется сам. В режиме shell строка уходит в оболочку устройства, как после `adb shell` (работают `|`, `;`, кавычки). Под строкой ввода видна точная команда, вывод идёт по мере появления, долгие команды (`logcat`, `top`) останавливает кнопка. История стрелками вверх и вниз, сохранённые команды справа. Интерактивную оболочку (голый `adb shell`) консоль не запускает и объясняет почему. Команды не проходят через cmd.exe: текст разбирается на аргументы самим приложением. Каждая команда попадает в журнал, коды сопряжения скрыты.
- **Защита от поломок:** системные приложения удаляются только для пользователя (`pm uninstall -k --user 0`) и возвращаются одной кнопкой. Установленные вами приложения перед удалением сохраняются на компьютер. Для важных пакетов (главный экран, клавиатура, сервисы Google, обновления) отдельное красное подтверждение. Пакеты, без которых перестанет работать сам adb, MaxOnDroid не трогает.

## Запуск из исходников (Windows 10)

1. Установите [Python 3.11 или новее](https://www.python.org/downloads/windows/). В установщике отметьте «Add python.exe to PATH».
2. Установите [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) (в архиве лежит `adb.exe`) и либо добавьте папку в `PATH`, либо после запуска укажите путь к `adb.exe` в настройках приложения. Если `adb` у вас уже работает из `cmd`, ничего делать не нужно.
   Для вкладки «Экран» скачайте архив `scrcpy-win64-…zip` со страницы [релизов scrcpy](https://github.com/Genymobile/scrcpy/releases) и распакуйте. Удобнее всего указать в настройках MaxOnDroid `adb.exe` из этой папки: тогда приложение само найдёт `scrcpy.exe` рядом.
3. В папке проекта выполните:

   ```bat
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   python -m maxondroid
   ```

## Проверка

```bat
pip install -r requirements-dev.txt
set QT_QPA_PLATFORM=offscreen
python -m pytest
ruff check .
```

Тесты используют поддельный `adb` (`tests/fake_adb.py`) с ответами в формате настоящих устройств, поэтому подключать устройства для них не нужно.

## Безопасность

- `adb` всегда запускается со списком аргументов, без командной оболочки Windows: имя устройства или путь не превратятся во вторую команду.
- Всё, что уходит в `adb shell` из ввода пользователя, экранируется для shell на устройстве.
- Приложение не открывает сетевых портов на компьютере и не отправляет в интернет никаких данных. Единственный запрос в интернет — скачивание свежей базы UAD-ng с GitHub, и только по кнопке «Обновить базу».
- Ключи `adb` (`%USERPROFILE%\.android\adbkey`) приложение не читает и не копирует.
- Подсеть не сканируется: устройства находятся только через mDNS, который они сами объявляют.

## Где хранятся данные

Если Python установлен из Microsoft Store, Windows хранит эти папки в `%LOCALAPPDATA%\Packages\PythonSoftwareFoundation.Python…\LocalCache\…`. Кнопки «Открыть папку» в MaxOnDroid открывают именно это место, а путь видно в настройках. В собранном установщике (этап 5) такой подмены нет.

| Что | Где |
|---|---|
| Настройки, список устройств, история изменений, пресеты | `%APPDATA%\MaxOnDroid` |
| Журнал команд и журнал диагностики `diag-*.log` (14 дней) | `%LOCALAPPDATA%\MaxOnDroid\logs` (меню «Справка» → «Открыть папку журналов») |
| Копии APK перед удалением, скачанная база UAD-ng | `%LOCALAPPDATA%\MaxOnDroid\data` |

Журнал диагностики пишет только время: какие команды adb выполнялись дольше секунды и где программа стояла, если окно не отвечало дольше полсекунды. Вывода команд и личных данных в нём нет; его можно приложить к сообщению об ошибке.

Форматы файлов описаны в [docs/formats.md](docs/formats.md).

## English

MaxOnDroid is a Windows desktop app for managing the Android devices on your home network (Android TV and phones) through `adb`. Every action is logged as the plain `adb` command it runs.

Stage 4 of 5 is done: device list with persistent numbered tokens, USB / address / pairing code / QR / mDNS connection, auto-reconnect, the Overview tab, the Apps tab (install APKs and split bundles, per-app actions, save APKs), the Debloat tab (packages grouped by publisher with removal risk 1-4, presets, undo history), the Remote tab (on-screen TV remote and PC keyboard shortcuts), the Screen tab (scrcpy mirroring with presets, MP4 recording, screenshots), the Files tab (browse, upload and download with drag and drop, new folder, rename, delete), the Console tab (adb and shell modes with history and saved commands), the command journal, Russian and English, light and dark themes. Run it from source: install Python 3.11+, have `adb` on `PATH` (or set its path in Settings), then `pip install -r requirements.txt` and `python -m maxondroid`. Tests: `pip install -r requirements-dev.txt`, `QT_QPA_PLATFORM=offscreen`, `python -m pytest`.
