# Этап 2: ручная проверка на реальных устройствах

Как и в первом этапе: отмечайте пункты и присылайте номера тех, что не прошли, вместе со строками из журнала команд (правый клик → «Копировать»). Для проверки удаления выбирайте безвредные пакеты (например, YouTube на телевизоре или предустановленную игру на телефоне), чтобы потом вернуть их через «Историю изменений».

## Предупреждение о сетевом adb

- [ ] 1. На «Обзоре» телевизора на жёлтой плашке две кнопки: «Выключить сетевой adb» и «Я понимаю риск, это моё устройство».
- [ ] 2. После «Я понимаю риск…» плашка сворачивается в одну строку с кнопкой «Подробнее», а жёлтое кольцо на номерке остаётся.
- [ ] 3. После перезапуска MaxOnDroid плашка по-прежнему свёрнута. «Подробнее → Снова предупреждать» возвращает полную плашку.

## Приложения

- [ ] 4. Вкладка «Приложения» за несколько секунд показывает список пакетов с версиями. Внизу «Показано N из M».
- [ ] 5. Поиск по части имени (например, `youtube`) и фильтры «Установленные мной», «Системные», «Удалённые» работают.
- [ ] 6. Установка APK кнопкой «Установить APK». Приложение появляется в списке, в журнале строка `adb -s … install -r …`.
- [ ] 7. Перетащите APK из Проводника в окно MaxOnDroid: открывается «Приложения», файл устанавливается.
- [ ] 8. Если есть файл `.apks` или `.xapk` (например, из SAI или APKPure), он ставится так же, в журнале `install-multiple`.
- [ ] 9. Установка APK, который новее уже установленного или подписан другим ключом, показывает понятную причину по-русски.
- [ ] 10. «Запустить» (или двойной щелчок) открывает приложение на телевизоре или телефоне.
- [ ] 11. «Отключить» и затем «Включить» меняют состояние в таблице.
- [ ] 12. «Ещё → Сохранить APK…» сохраняет `.apk`, а для приложения из нескольких частей — `.apks`. Кнопка «Открыть папку» открывает Проводник.
- [ ] 13. Удаление установленного вами приложения: в подтверждении есть галочка «Сохранить APK перед удалением». После удаления «Чистка → История изменений → Отменить выбранные» ставит его обратно.

## Чистка

- [ ] 14. Вкладка «Чистка» показывает «База UAD-ng: … пакетов · встроенная». Справа описание выбранного пакета на английском.
- [ ] 15. Кнопки «Рекомендуется», «Для опытных», «Эксперт», «Опасно» и «Пакеты не из базы» меняют список.
- [ ] 16. Отметьте безвредный пакет и нажмите «Удалить». Пакет становится «Удалено», в «Истории изменений» появляется запись.
- [ ] 17. Попытка удалить лаунчер или клавиатуру показывает красное предупреждение «Важные системные пакеты». Нажмите «Отмена».
- [ ] 18. «История изменений → Вернуть всё» возвращает всё, что удаляли и отключали, в обратном порядке.
- [ ] 19. «Пресеты → Сохранить отмеченные как пресет…» создаёт JSON-файл. «Применить пресет…» на другом устройстве сначала показывает, сколько пакетов изменится, а сколько уже сделано или отсутствует.
- [ ] 20. «Обновить базу» скачивает свежий список (подпись меняется на «обновлена» и сегодняшнюю дату). Без интернета появляется понятная ошибка, и прежняя база остаётся.

## Доработка: группы по издателю и риск удаления

- [ ] 21. «Чистка» показывает группы: «Android (система)», «<производитель> — производитель устройства», «Google», другие издатели и «Остальные» (там, например, Telegram и Discord, если у издателя одно приложение).
- [ ] 22. Колонка «Риск удаления» показывает «1 · без последствий» … «4 · может не загрузиться». Кнопки «1»–«4» фильтруют список, «4» по умолчанию выключена.
- [ ] 23. Галочка у группы отмечает все её пакеты; если снять один, у группы становится частичная отметка.
- [ ] 24. «Приложения»: колонка «Издатель» и фильтр «Все издатели» работают.
- [ ] 25. «Пресеты → Открыть папку пресетов» и в настройках «Открыть папку настроек/журналов» открывают папки в Проводнике без ошибки. В настройках внизу виден путь, где они лежат.
