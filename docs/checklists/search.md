# Поиск файлов и исправления консоли: ручная проверка

Присылайте номера пунктов, которые не прошли.

## Поиск

- [ ] 1. «Файлы», телефон, папка `/sdcard`. Начните вводить в поле поиска «img»: появляется «Собираю список файлов…» с кнопкой «Отмена», через несколько секунд — таблица «Имя | Расположение | Размер | Изменён».
- [ ] 2. Меняйте запрос: результаты обновляются сразу, без повторного «Собираю список…».
- [ ] 3. Русское имя в другом регистре находится: например, папка «Отпуск» по запросу «отпуск». Расширение в поиске по имени не учитывается.
- [ ] 4. Запрос `.jpg` показывает только файлы с этим расширением.
- [ ] 5. В списке типов выберите «Фото», затем «Видео», «Документы», «APK», «Папки»: показывается только нужное.
- [ ] 6. «Свои расширения…»: появляется маленькое поле, впишите `pdf, mp4`, найдутся файлы с обоими расширениями.
- [ ] 7. Двойной щелчок по найденному файлу открывает его папку, файл выделен. По найденной папке — открывает её.
- [ ] 8. Выделите найденные файлы: «Скачать…», «Переименовать», «Удалить» работают прямо в результатах. При удалении в подтверждении видны полные пути.
- [ ] 9. Esc или крестик в поле поиска возвращает к содержимому папки.
- [ ] 10. Зайдите в DCIM и найдите что-нибудь: результаты только из DCIM, и список с устройства заново не собирается.
- [ ] 11. Кнопка «Обновить» во время поиска собирает список заново (после того как на телефоне появились новые фото).
- [ ] 12. Начните поиск на телефоне с большим количеством файлов и сразу нажмите «Отмена»: поиск останавливается с сообщением.

## Исправления

- [ ] 13. Впишите в адрес `/data` и нажмите Enter: сообщение «Нет доступа к папке /data», а не «Папка пуста».
- [ ] 14. Консоль, режим adb: `shell ls -l /sdcard/ | grep D`. В строке «Будет выполнено» палка без кавычек, команда выводит DCIM, Download, Documents.
- [ ] 15. Консоль, режим shell: `ls -l /sdcard | grep D` (без косой черты). Статус объясняет: код 1 и пустой вывод — обычно «ничего не найдено».
