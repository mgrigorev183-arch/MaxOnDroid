# Этап 5: ручная проверка

Установщик, встроенные adb и scrcpy, проверка обновлений и исправления после проверки безопасности. Проверяйте на своём компьютере с Windows 10 установщиком со [страницы выпуска 0.9.0](https://github.com/mgrigorev183-arch/MaxOnDroid/releases/tag/v0.9.0). Присылайте номера пунктов, которые не прошли.

Перед началом закройте MaxOnDroid, запущенный из исходников, и остановите свой adb (`adb kill-server`), чтобы проверить именно встроенный.

## Скачивание и установка

- [ ] 1. На странице выпуска есть `MaxOnDroid-0.9.0-setup.exe` и `MaxOnDroid-0.9.0-setup.exe.sha256`, а в описании выпуска указан SHA-256.
- [ ] 2. `certutil -hashfile MaxOnDroid-0.9.0-setup.exe SHA256` (или `Get-FileHash` в PowerShell) выдаёт ту же строку, что на странице выпуска.
- [ ] 3. При запуске установщика Windows не просит прав администратора (нет жёлтого окна UAC). Если появилось синее окно SmartScreen, «Подробнее» → «Выполнить в любом случае» запускает установку.
- [ ] 4. Установщик предлагает язык; выбран русский — все страницы на русском. (По желанию: запустите ещё раз, выберите English и отмените — страницы на английском.)
- [ ] 5. На странице лицензии виден текст GPL-3.0.
- [ ] 6. Папка по умолчанию — `C:\Users\<вы>\AppData\Local\Programs\MaxOnDroid`.
- [ ] 7. Впишите `C:\Program Files\MaxOnDroid` и нажмите «Далее»: появляется объяснение, что нужны права администратора, с предложением папки в профиле; дальше установщик не идёт.
- [ ] 8. Верните папку по умолчанию, отметьте «Значок на рабочем столе», установите: в конце предлагается запустить MaxOnDroid, программа открывается.
- [ ] 9. В меню «Пуск» есть MaxOnDroid, на рабочем столе значок — жёлтый кружок-номерок; у окна программы и в панели задач тот же значок.

## Встроенные adb и scrcpy

- [ ] 10. В настройках путь к adb пустой (или сброшен), а устройства всё равно находятся: в настройках под полем adb написано «Используется …\MaxOnDroid\tools\scrcpy\adb.exe».
- [ ] 11. Подключение телефона по Wi-Fi (код сопряжения или QR) и телевизора проходит как раньше; журнал и «Обзор» работают.
- [ ] 12. Вкладка «Экран»: окно scrcpy открывается без указания пути к scrcpy, в окне виден экран устройства, работает ввод по-русски с клавиатуры как физической.
- [ ] 13. Запись в MP4 и скриншот сохраняются в `Изображения\MaxOnDroid`, «Открыть папку» открывает её в Проводнике (в установленной программе подмены папок Microsoft Store нет).
- [ ] 14. Вкладки «Приложения», «Чистка», «Файлы» с поиском, «Консоль» работают так же, как в версии из исходников (выборочно, по одному действию).

## Проверка обновлений

- [ ] 15. Меню «Справка» → «Проверить обновления»: окно «Обновлений нет» с текстом «У вас последняя версия: 0.9.0».
- [ ] 16. В настройках есть флажок «Проверять обновления раз в день», он включён; снимите его, сохраните, перезапустите программу — флажок остаётся снятым. Включите обратно.
- [ ] 17. Без интернета (выключите Wi-Fi на компьютере) «Проверить обновления» показывает «Не удалось проверить», программа не зависает.

## Исправления после проверки безопасности

- [ ] 18. Консоль, режим adb: введите `pair 192.168.1.10:37000 123456` (адрес не обязан существовать) и выполните. Закройте и откройте программу, листайте историю стрелкой вверх: вместо кода видно «••••••».
- [ ] 19. Окна подтверждения (удаление приложения, перезагрузка) выглядят как раньше: обычный текст, имена пакетов на месте.

## Обновление поверх и удаление

- [ ] 20. Запустите тот же установщик ещё раз поверх установленной программы, пока MaxOnDroid открыт: установщик предлагает закрыть программу, установка проходит, настройки и список устройств на месте.
- [ ] 21. «Параметры» → «Приложения» → MaxOnDroid → «Удалить»: удаление спрашивает, стереть ли ваши данные (по умолчанию «Нет»). Ответьте «Нет»: папка программы удалена, `%APPDATA%\MaxOnDroid` осталась, скриншоты в «Изображениях» остались.
- [ ] 22. Установите снова и удалите, ответив «Да»: `%APPDATA%\MaxOnDroid` и `%LOCALAPPDATA%\MaxOnDroid` удалены, скриншоты в «Изображениях» остались.
