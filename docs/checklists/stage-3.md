# Этап 3: ручная проверка на реальных устройствах

Для вкладки «Экран» нужен scrcpy: скачайте `scrcpy-win64-…zip` со страницы https://github.com/Genymobile/scrcpy/releases, распакуйте и укажите в настройках MaxOnDroid `adb.exe` из этой папки (или сам `scrcpy.exe` в поле «scrcpy»). Присылайте номера пунктов, которые не прошли, и строки из журнала команд.

## Пульт

- [ ] 1. Кнопки крестовины, «ОК», «Назад», «Домой», «Меню» управляют телевизором. Каждое нажатие — строка `input keyevent …` в журнале с номерком телевизора.
- [ ] 2. «Громче», «Тише», «Без звука» меняют громкость. «Канал +/−» работают в приложении ТВ (если у телевизора есть тюнер).
- [ ] 3. «Пауза», «Перемотка назад/вперёд», «Предыдущее/Следующее» работают в плеере (YouTube, VLC).
- [ ] 4. «Питание» усыпляет телевизор, повторное нажатие будит. Подключение по Wi-Fi после пробуждения остаётся или восстанавливается само.
- [ ] 5. Удержание «Домой» дольше полсекунды — долгое нажатие (на Google TV обычно открывает панель или Ассистента).
- [ ] 6. Щёлкните по пульту: рамка становится цветной, подсказка меняется. Стрелки, Enter, Esc, пробел, +/−, PgUp/PgDn работают с клавиатуры.
- [ ] 7. Удерживая стрелку, листаете список; удерживая Enter, «ОК» нажимается один раз.
- [ ] 8. Откройте на телевизоре поиск, наберите в поле пульта `matrix` и нажмите «Отправить текст»: текст появляется на телевизоре.
- [ ] 9. Русский текст не отправляется, а показывается понятное объяснение.

## Экран

- [ ] 10. Без scrcpy вкладка показывает «Не найден scrcpy» с кнопками «Скачать scrcpy» и «Указать путь». Скриншот при этом работает.
- [ ] 11. После указания scrcpy видна строка «scrcpy X.Y готов».
- [ ] 12. «Открыть экран» открывает окно с изображением телевизора, мышь и клавиатура в нём управляют телевизором. Заголовок окна — номерок и имя устройства.
- [ ] 13. Звук телевизора идёт через компьютер (Android 11+), а галочка «Передавать звук» его отключает.
- [ ] 14. Пресет «Скорость» заметно снижает задержку по Wi-Fi. Параметры в «Дополнительно» сохраняются после перезапуска.
- [ ] 15. «Закрыть» закрывает окно scrcpy. Закрытие MaxOnDroid закрывает все окна scrcpy, открытые из него.
- [ ] 16. Экраны двух устройств можно открыть одновременно, каждое в своём окне.
- [ ] 17. «Начать запись» открывает окно записи, «Остановить запись» сохраняет `.mkv` в папку снимков, файл открывается в проигрывателе (например, VLC).
- [ ] 18. «Скриншот» сохраняет PNG в `Изображения\MaxOnDroid`, превью появляется на вкладке, «Копировать» кладёт картинку в буфер (вставьте в Paint).
- [ ] 19. «Изменить…» меняет папку снимков, «Открыть папку» открывает её в Проводнике.
- [ ] 20. Онлайн-кинотеатр в окне scrcpy и на скриншоте чёрный, а меню и обычные приложения видны (ожидаемо).
