# Этап 1: ручная проверка на реальных устройствах

Автотесты проверяют логику на поддельном adb. Этот список проверяет то, что можно увидеть только на настоящих устройствах. Отмечайте пункты и присылайте номера тех, что не прошли, вместе с текстом из журнала команд (правый клик по строке → «Копировать»).

## Подготовка

- [ ] 1. Приложение запускается командой `python -m maxondroid`, окно открывается без ошибок в консоли.
- [ ] 2. Если adb не найден, сверху видна красная плашка «Не найден adb» с кнопкой «Указать путь». После выбора `adb.exe` в настройках плашка пропадает.

## Телевизор (Android 12)

- [ ] 3. Если телевизор уже подключён по старому режиму (`adb connect IP:5555`), он появляется в списке с номерком 01 или 02, жёлтым кольцом и значком предупреждения.
- [ ] 4. На вкладке «Обзор» видна жёлтая плашка «Сетевой adb открыт для всей сети». Данные заполнены: модель, Android 12, патч безопасности, память, IP-адрес. Для батареи написано «Нет батареи».
- [ ] 5. Сопряжение по коду: на телевизоре «Настройки → Для разработчиков → Отладка по Wi-Fi → Подключить устройство с помощью кода». В MaxOnDroid «Подключить устройство → По коду», ввести IP, порт и код. Появляется «Подключено: …», телевизор в списке без жёлтого кольца (подключение «Wi-Fi, сопряжение»). Если пункта «Отладка по Wi-Fi» в меню телевизора нет, отметьте это.
- [ ] 6. Кнопка «Выключить сетевой adb» на плашке: после подтверждения в журнале строка `adb -s … usb`, плашка пропадает. Если телевизор был подключён только по старому режиму, он уходит в «не в сети» (это ожидаемо).
- [ ] 7. «Перезагрузить → Перезагрузить»: телевизор перезагружается, номерок становится контурным, после загрузки снова сплошной (при сопряжении — сам, без действий).

## Телефоны (Android)

- [ ] 8. Телефон по USB: появляется сам. Если на телефоне запрос «Разрешить отладку?» ещё не подтверждён, номерок с вырезом и подсказка на «Обзоре», после подтверждения номерок становится сплошным.
- [ ] 9. Сопряжение по QR-коду: «Подключить устройство → По QR-коду», на телефоне «Отладка по Wi-Fi → Подключить устройство с помощью QR-кода», навести камеру. Появляется «Подключено». Если не срабатывает за минуту, отметьте модель роутера.
- [ ] 10. Тот же телефон по USB и Wi-Fi одновременно: в списке одна строка, номерок тот же.
- [ ] 11. «Найдено в сети»: видны устройства с включённой отладкой по Wi-Fi. Кнопка «Подключить» подключает.
- [ ] 12. Выключить и включить Wi-Fi на телефоне: в течение пары минут он переподключается сам (номерок снова сплошной).

## Окно

- [ ] 13. «Вид → Язык → English» переключает весь интерфейс без перезапуска, обратно — тоже.
- [ ] 14. «Вид → Тема»: светлая, тёмная и «Как в Windows» (меняется вместе с темой Windows).
- [ ] 15. «Переименовать» меняет название в списке. Название сохраняется после перезапуска, номерки тоже.
- [ ] 16. Журнал команд: у каждой строки номерок устройства, ошибки красным с текстом ошибки, «Свернуть журнал» сворачивает и запоминается.
- [ ] 17. Шрифты: номерки и заголовки набраны Bahnschrift (узкий шрифт), текст — Segoe UI. Ничего не обрезается при ширине окна 900 px.
