# Этап 4: ручная проверка

Вкладки «Файлы» и «Консоль», плюс исправления «Экрана» (ширина окна, запись в MP4). Присылайте номера пунктов, которые не прошли.

## Экран

- [ ] 1. Окно MaxOnDroid на полэкрана, вкладка «Экран», раскрыт раздел «Дополнительно»: правый край не обрезан, кнопка «Раскладка на устройстве…» и кнопки папки видны целиком.
- [ ] 2. Новая запись сохраняется в `.mp4`. Остановите её кнопкой: статус пишет «Завершаю запись…», потом «Запись сохранена». Файл открывается встроенным плеером Windows («Кино и ТВ» или «Медиаплеер»), со звуком.
- [ ] 3. Закройте окно записи scrcpy крестиком вместо кнопки: файл тоже открывается.
- [ ] 4. Переключите формат на MKV и запишите ещё раз: получается `.mkv`.

## Файлы

- [ ] 5. Выберите телефон, вкладка «Файлы»: видна папка `/sdcard` (DCIM, Download, …), папки сверху, у файлов размер и дата.
- [ ] 6. Двойной щелчок по папке открывает её, стрелка вверх (или Backspace) возвращает назад, и та папка остаётся выделенной.
- [ ] 7. Впишите в адрес `/data` и нажмите Enter: появляется сообщение «Нет доступа», список остаётся прежним.
- [ ] 8. Кнопка с папкой и плюсом справа от адреса создаёт папку с русским именем.
- [ ] 9. «Переименовать» (или F2) меняет имя файла.
- [ ] 10. «Удалить» (или Delete) сначала спрашивает и перечисляет имена; «Отмена» ничего не удаляет, подтверждение удаляет.
- [ ] 11. «Загрузить» → «Файлы…» копирует файл с компьютера в открытую папку, список обновляется.
- [ ] 12. Перетащите несколько файлов и APK из Проводника на вкладку «Файлы»: они копируются в открытую папку (APK не устанавливается).
- [ ] 13. Выделите фото и нажмите «Скачать…»: после выбора папки файлы появляются на компьютере, кнопка «Открыть папку» её открывает.
- [ ] 14. Начните скачивать большую папку (DCIM) и нажмите «Отмена»: копирование останавливается, программа сообщает об этом.
- [ ] 15. То же на телевизоре: видна его память, загрузка APK в Download работает.

## Консоль

- [ ] 16. Режим adb, введите `devices -l`: под строкой видно «Будет выполнено: adb devices -l», после Enter — список устройств и «Готово · код 0».
- [ ] 17. Режим adb, `shell getprop ro.build.version.release` с выбранным устройством: в превью подставлен `-s …`, выводится версия Android.
- [ ] 18. Режим shell, `ls -l /sdcard/ | grep D`: работает как в `adb shell`.
- [ ] 19. Режим adb, `logcat`: строки идут непрерывно, «Остановить» прекращает.
- [ ] 20. Введите `shell` без команды: превью объясняет, что интерактивная оболочка здесь не работает, кнопка «Выполнить» неактивна.
- [ ] 21. Стрелки вверх и вниз в строке ввода листают историю; после перезапуска программы история на месте.
- [ ] 22. «Сохранить…» добавляет команду справа; двойной щелчок подставляет её, «Выполнить» запускает, «Удалить» убирает. После перезапуска сохранённые команды на месте.
- [ ] 23. Каждая выполненная команда видна в журнале внизу.
